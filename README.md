🎮 Tic-Tac-Toe Game

A simple, interactive, and responsive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

This project is created as a beginner-friendly frontend project to practice JavaScript concepts such as DOM manipulation, event handling, functions, arrays, and game logic.

✨ Features
🎮 Two-player Tic-Tac-Toe game
❌ X and ⭕ O player turns
🏆 Automatic winner detection
🤝 Automatic draw detection
🔄 Reset game functionality
🆕 New game functionality
🚫 Automatically disables the board after the game ends
📱 Responsive user interface
⚡ No external libraries or frameworks required
🛠️ Technologies Used
HTML5 – Structure of the game
CSS3 – Styling and responsive design
JavaScript – Game logic and interactivity
🎯 How to Play
Open the game in your browser.
The first player places O.
The second player places X.
Players take turns selecting an empty box.
The first player to get three matching symbols in a row wins.
If all boxes are filled without a winner, the game ends in a draw.
Use Reset or New Game to play again.
